# 🧠 RNN Student Performance Prediction System

Predicts student **Pass / Fail** using an LSTM Recurrent Neural Network
trained on 5 weeks of weekly academic behaviour data.

---

## 📁 Project Structure

```
rnn_student_project/
│
├── dataset.xlsx        ← Student weekly data (50 students × 5 weeks)
├── train_rnn.py        ← Full training pipeline (run locally)
├── predict.py          ← predict_student() function + CLI
├── app.py              ← Streamlit web UI (auto-trains on cloud)
├── model.h5            ← Saved LSTM model  (generated by train_rnn.py)
├── scaler.pkl          ← Saved StandardScaler (generated by train_rnn.py)
├── requirements.txt    ← Python dependencies
└── README.md           ← This file
```

---

## 🚀 How to Run Locally

```bash
# 1. Create virtual environment
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Mac/Linux

# 2. Install dependencies
pip install -r requirements.txt

# 3. Train the model (generates model.h5 + scaler.pkl)
python train_rnn.py

# 4. (Optional) Test via command line
python predict.py

# 5. Launch Streamlit UI
streamlit run app.py
```

---

## ☁️ Deploy to Streamlit Cloud

1. Push ALL files (including `model.h5` and `scaler.pkl`) to GitHub
2. Go to https://share.streamlit.io
3. Click **Create App** → select your repo
4. Set main file: `app.py`
5. Click **Deploy** — live in ~2 minutes!

> **Note:** `app.py` auto-trains the model if `model.h5` is missing,
> so deployment works even without pre-generated model files.

## 🧠 Model Architecture

```
Input  → (5 timesteps, 4 features)
LSTM_1 → 64 units, return_sequences=True
Dropout → 30%
LSTM_2 → 32 units
Dropout → 20%
Dense  → 16 neurons, ReLU
Output → 1 neuron, Sigmoid → Pass probability
```

## 📊 Dataset Columns

| Column       | Description                    |
|--------------|-------------------------------|
| student_id   | Unique student identifier      |
| week         | Week number (1–5)              |
| attendance   | Attendance % (0–100)           |
| assignment   | Assignment marks (0–100)       |
| quiz         | Quiz marks (0–100)             |
| study_hours  | Weekly study hours (0–15)      |
| result       | 1 = Pass, 0 = Fail (per student)|
